HandsMen Threads: Salesforce Automation
Modernizing Men's Fashion CRM with Intelligent Workflows

Ringkasan Project
Sistem CRM Salesforce yang dirancang untuk mengotomatisasi operasional bisnis dan manajemen loyalitas pelanggan pada brand fashion HandsMen Threads.

Fitur Utama
1. Dynamic Loyalty Program: Update status pelanggan otomatis (Gold/Silver/Bronze) via Scheduled Flow setiap pukul 02:00 AM.
2. Automated Communication: Konfirmasi pesanan instan dan notifikasi stok rendah (<5 unit) via email otomatis.
3. Bulk Inventory Processing: Pemrosesan pesanan massal dan sinkronisasi finansial harian setiap tengah malam menggunakan Apex Batch.
4. Robust Data Model: Arsitektur objek kustom (HandsMen_Customer__c, HandsMen_Order__c) untuk integritas data yang tinggi.

Tech Stack
1.Salesforce Platform: Flow Builder, Apex Classes, Triggers, & Email Templates.
2.Metadata: Custom Objects, Translations, & Validations.
